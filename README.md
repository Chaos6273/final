КиноТрендОткрытие

Краткое описание проекта

КиноТрендОткрытие - это интерактивный веб-каталог сериалов, разработанный как frontend-проект.  
Сайт позволяет пользователю открывать новые сериалы, просматривать информацию о них и сохранять понравившийся контент в избранное.

Проект демонстрирует работу современного пользовательского интерфейса без серверной части, используя данные из внешнего API.  
Все взаимодействия происходят динамически без перезагрузки страницы.

Основные возможности:
- просмотр каталога сериалов
- поиск по названию
- фильтрация по жанрам
- просмотр подробной информации
- добавление сериалов в избранное
- сохранение данных пользователя через LocalStorage



Используемые технологии

- HTML5 - структура веб-страниц  
- CSS3 / TailwindCSS - стилизация и адаптивный дизайн  
- JavaScript (ES6) - логика приложения  
- Fetch API - получение данных из внешнего API  
- LocalStorage - хранение избранных сериалов  

- TVMaze API - источник данных о сериалах
